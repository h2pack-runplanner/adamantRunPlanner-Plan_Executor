# Execution-plan fixtures

These six files are byte-for-byte mirrors of the execution fixtures in
RunPlanner-main: `f-opening`, `fg`, `fg-ixion-chaos`, `fg-anomaly`,
`automatic-boss`, and `underworld-fgh`. They cover the F opening, F/G route,
Ixion/Chaos additional exit, G anomaly, automatic boss effects, and the H
Mourning Fields room layout. They are checked-in protocol data; Plan Executor
tests never import planner implementation code.
